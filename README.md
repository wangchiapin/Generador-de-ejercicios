# 語法練習單產生器 · Generador de ejercicios

給華語老師用的小工具：**用任何 AI 出題，貼回來，自動轉換、檢查，一鍵印出練習單和答案頁。**
專為教西班牙語母語學生設計（練習單說明為西班牙文，內容為繁體中文）。

網址（開啟 GitHub Pages 後）：https://wangchiapin.github.io/Generador-de-ejercicios/

## 三個頁面

三頁頂端有同一條分頁列，可互相切換；登入同步的按鈕也在這條列上。

| 頁面 | 檔案 | 用途 |
|---|---|---|
| 語法練習單產生器 | `index.html` | 出**紙本練習單**：AI 出題 → 貼回檢查 → 列印 |
| 課堂口說練習設計 | `oral-practice.html` | 設計**課堂口說活動**：組合提示詞，貼給 AI 取得分析與練習（分「設計」「歷史紀錄」兩個分頁） |
| 對話教材 Prompt 產生器 | `dialogue-prompt.html` | 依程度、主題等條件產生對話教材與縮圖的指令；填過的欄位重新整理後會保留，可「全部清空」 |

三頁在同一個網址底下，所以**共用「學生常犯的錯」清單**（在一邊寫過，另一邊自動帶出）。口說頁可以按「從練習單帶入語法點」；反過來，口說頁的每筆歷史紀錄有「帶到練習單」按鈕，會把語法點（最多 3 個）和主題帶到練習單。

### 文法速查表（grammar-reference.html，給學生用）

- **獨立頁面，沒有老師的分頁列**，網址直接給學生：`https://wangchiapin.github.io/Generador-de-ejercicios/grammar-reference.html`（**網址分大小寫**，G 要大寫）。
- **四種語言可選**：繁體中文／简体中文／Español／English，右上角選單切換。第一次依瀏覽器語言自動選，之後會記住；網址可帶語言，例如 `...grammar-reference.html?lang=en`，搜尋字用 `#q=…`（例如 `?lang=sc#q=被`）。介面文字、文法點標題、說明、例句翻譯都會跟著換。中文介面的例句只放中文，不放翻譯或拼音。
- 內容：《當代中文課程》Book 1–4 共 349 個文法點，每點有四語標題、說明和例句。可輸入「了」「比」「ba」或各語言的關鍵字（comparar、passive、被動…）搜尋，也可以依冊、課慢慢點開。
- 資料在 `grammar-data.js`（`window.GRAMMAR`），要改說明或例句改這個檔，不用動頁面。每筆的 `t` 是標題、`d` 是說明、`ex` 是例句；`k` 是搜尋用關鍵字（自動產生、不顯示）。**簡體是由繁體自動轉換**（OpenCC `tw2s`，只換字形、保留台灣用語），要改簡體請改繁體再重新轉換。
- **目前說明為草稿，尚待老師逐點審核**；還沒有「常見錯誤」。
- **與其他三頁連動（老師用）**：練習單、口說練習、對話產生器的語法點欄，打字時會跳出速查表的文法點可選（`grammar-picker.js`，共用 `grammar-data.js`）。速查表網址加 `?teacher=1`（會記住，`?teacher=0` 關閉）後，每個文法點多三個按鈕：帶到練習單／口說練習／對話產生器。學生看不到這些按鈕。
- **例句拼音**：每個例句有 `p` 欄（拼音，由 pinyin-pro 依簡體字自動產生，套用 corre 管理頁的台灣讀音規則（台灣讀音例外表、們／麼／間／車、一／不變調、GoodTeacher 多音字表，鑰匙 yuè shi、當真 dāng zhēn、東西 dōng xi 等例外，介詞「為」念 wèi），**尚待審核**）。頁面右上角「拼音／Pinyin」按鈕可開關，西文、英文介面預設顯示，中文介面預設隱藏，選擇會記住。
- **多選帶走**（老師模式）：每個文法點有「選取」鈕，選好後畫面下方出現一條工具列，可一次把多個文法點帶到練習單（最多 3 個）、口說練習（最多 6 個）或對話產生器（最多 3 個）；按鈕文字跟著介面語言換。
- **自動附教材參考**：練習單、口說練習、對話產生器的語法點，只要名稱和速查表的標題完全一樣（用跳出選單選的就一樣），出題指令會自動附上該點的說明和前 3 個例句，不用另外勾選。手打的語法點不會附。

### 課堂口說練習設計（oral-practice.html）

- 語法點可用「＋」新增，最多 6 個；填 2 個以上會多要一份「組合練習方案」（語法點的關係、教學順序、哪些練習適合放在一起、綜合任務；不適合合併時會建議分開教）。
- 可填程度（A1～B2）、課堂時間、主題、已學詞彙、教材內容、例句。
- 英文翻譯、西班牙文翻譯分開勾選。
- 9 種練習模式可勾選；不勾就讓 AI 自己挑。
- 「後續指令」按鈕：一鍵複製常用的追問，貼回同一個 AI 對話繼續用。
- 歷史紀錄：貼上 AI 的分析，連同當時的設定一起存起來，可搜尋、載入設定、修改、刪除，也能匯出／匯入備份。預設**只存在這台裝置的瀏覽器裡**，換裝置或清除瀏覽器資料就看不到，重要的請定期匯出備份。
- 雲端同步（選用）：按「用 Google 登入同步」，紀錄會存到 Firebase 專案 `moneybook-50481`（路徑 `users/{uid}/oralHistory`），換手機或電腦登入同一個 Google 帳號就看得到。不登入照常使用。
  - **使用前要在 Firebase 的 Firestore 規則加上這兩段**（放在 `match /databases/{database}/documents {` 裡面）。規則整個專案只有一份，要在現有規則上**加**，不要整份換掉（口說歷史用第一段，練習單清單用第二段）：
    ```
    match /users/{uid}/oralHistory/{id} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /users/{uid}/worksheetProjects/{id} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    ```
  - 登入時才會同步刪除；沒登入時刪掉的紀錄，下次登入更新時可能會從雲端再出現。

## 練習單產生器能做什麼

> **我的練習單**：頁面右上角「專案 ▾」選單裡的「我的練習單」可以把目前這份存進清單，之後隨時開啟、用目前這份覆蓋、刪除、搜尋。預設存在瀏覽器；登入 Google 後同步到 Firebase（`users/{uid}/worksheetProjects`），跟口說頁共用同一個登入。原本的「儲存專案」（下載成檔案）仍然可以用。

1. **出題**：填語法點（1～3 個）、程度、題數，工具產生一段「出題指令」，複製後貼給任何 AI（Claude、ChatGPT、Gemini 都可以）。
2. **貼回**：把 AI 的回覆整段貼回來。前後有說明文字、程式碼框、多餘逗號都沒關係，格式錯了會用中文告訴你錯在哪裡。
3. **檢查**：每題自動檢查（空格數、答案在不在詞庫、排序有沒有打散、選擇題答案分佈、簡體字、大陸用語…），可以直接修改、換一題、刪除、新增。
4. **輸出**：列印或存成 PDF，練習頁和答案頁分開（答案頁固定另起一頁）。

## 六種題型

選詞填空・段落填空（一段生活情境短文）・排序・選擇・改錯・西翻中

## 綜合練習（2～3 個語法點）

語法點欄填 2～3 個，就會變成綜合練習：

- 出題指令會要求 AI 在每題標上用到哪些語法點，並**至少有指定比例（30%／50%／70%／全部）的題目同一句混合使用 2 個以上語法點**。
- 檢查頁顯示各語法點的題數、混合題數，不足會提醒；每題可以手動改標記。
- 答案頁每題旁有語法點標籤，最後有分布統計（學生那頁不印標籤）。
- 常見錯誤清單依語法點分開記住。

## 自動轉換

- **拼音**（依台灣常用讀音處理破音字，可自己加「讀音修正」）、**注音**、**簡體字**。
- 答案頁可選擇顯示拼音、注音、簡體；練習頁可選擇在字上方標拼音或注音。
- 可輸出**句子庫**（JSON／CSV，含拼音、注音、簡體、西文、語法點標記），之後可匯入遊戲或其他教材。

## 使用注意

- **單一 HTML 檔，沒有後端**；資料自動存在你自己的瀏覽器裡，另可「儲存專案」成檔案、之後再開啟。
- 拼音、簡體轉換使用網路上的函式庫（pinyin-pro、opencc-js），**第一次載入需要網路**。
- 拼音、注音是電腦自動產生，**印給學生前請老師再確認**（輕聲、少數破音字可能與台灣習慣不同）。
- AI 出的題目一定要老師看過；工具能檢查格式與數量，無法保證每句都自然、答案唯一。

## 技術

純 HTML／CSS／JavaScript，單一檔案 `index.html`。
使用 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)、[opencc-js](https://github.com/nk2028/opencc-js)。
風格：無印風，無品牌色，可直接列印。
